# Telecom Customer Churn Prediction

## 📌 Project Overview
This machine learning project predicts customer churn in a telecom company using classification models.  
The goal is to identify at-risk customers and support retention strategies through data-driven insights.

## 🧠 Problem Statement
Customer churn significantly impacts revenue. By predicting churn early, telecom providers can take proactive retention actions.

## 🗂 Dataset
- Source: Telecom customer dataset
- Features include:
  - Demographics
  - Services used
  - Contract & payment information

## ⚙️ Tools & Technologies
- Python
- Pandas, NumPy
- Scikit-learn
- Matplotlib, Seaborn
- Jupyter Notebook

## 📊 Machine Learning Models
- Logistic Regression
- Decision Tree
- Random Forest
- Model evaluation using:
  - Confusion Matrix
  - ROC-AUC Curve
  - Accuracy, Precision, Recall

## 📈 Results
- Achieved **85%+ accuracy**
- Identified high-risk churn segments
- Visualized model performance using ROC curve and confusion matrix
